# 链表
对于循环链表，需要注意的是，当我们使用尾插法构建时，我们在插入的时候，需要时刻保证尾指针指向尾部，此时改变指针在C语言中需要使用**二级指针**！

对于双向循环链表, 需要注意的是, 在插入时, 不要忘记对头节点的前一个节点的后继, 和后一个节点的前继进行修改!

stack->s = (int*)malloc(m * sizeof(int));

# 队列
使用顺序表构建队列时，需要注意的是**f指向列头，r指向实际队尾的下一个位置**
构建`size()`函数时，需要注意
```c
return (q->r - q->f + q->MaxNum) % q->MaxNum;
```
解决杨辉三角打印问题，技巧是在没行的末尾加上一个0方便和最后一个1相加得到下一行的数据，因此我们每行需要处理的队列次数为 i  + 1 ，其中 i 为行号
# 二叉树
- n 个节点的二叉树有 n + 1 个空指针
- 线索二叉树的构建不能忘记处理最后一个节点的`rtag` 为 1
	- 意义：方便寻找“中序序列”中的前驱和后继，提高遍历速度，同时非递归中序遍历，不需要栈 
- 任何非空二叉树，设有叶子节点 $n_0$ 个，度为 1 的节点 $n_1$ 个，度为 2 的节点为 $n_2$ 个，则我们有：
  $$
	  n_2 = n_0 - 1
  $$
- 二叉树的表示
	- 顺序表示，对于非完全二叉树的是普通二叉树，使用顺序表示，最坏情况下可能出现**k + 1 个节点却需要申请 $2^{k + 1}-1$ 空间 ** 
- 在完全二叉树中，度为 1 的节点的数量只可能是 0 或者 1 
- 哈夫曼树不存在度为 1 的节点

# 字典
- 表示方法：顺序表示、链表表示、哈希表示
- 平均检索长度(ASL)
  $$
	  ASL(n)=\sum_{i=1}^np_ic_i
  $$
  - 顺序检索 $ASL(n)=\frac{n+1}{2} (successfull)\ n(failed)$  
  - 二分查找，等概率下，成功和失败的ASL均为 $o(log_2n)$ 
# 二叉排序树

- 最好ASL：$log_2(n)$
