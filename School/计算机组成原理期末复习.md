# 概念辨析
- 机器字长：CPU 在一次运算中，能够直接处理的二进制数据的位数，决定了通用寄存器的宽度和 ALU 的宽度
- 数据线位数：决定了的单次数据传输量
# 计算机系统概述
- 电子计算机可以分为电子模拟计算机和电子数字计算机，通常按照以应用为中心的分类方式将电子数字计算机进一步分为通用计算机和专用计算机
- 程序运行时间 = CPU 时钟周期总数 x 时钟周期时间
- 计算机硬件由存储器、运算器、输入输出设备、控制器、总线构成
- 机器字长：运算器进行二进制数运算的位数
- **字节是存储的基本单位**
- 存储程序：
	- 冯诺依曼结构(普林斯顿结构)：指令和数据放在同一存储器
	- 哈佛结构：指令和数据分别放在两个存储器
- 冯诺依曼计算机主要设计思想：
	- 有运算器、控制器、存储器、输入设备、输出设备五大部分构成计算机硬件系统
	- 采用二进制代码表示数据和指令
	- 采用存储程序控制方式（指令驱动方式）
## 计算机性能指标
### CPU 指标
- 时钟周期：CPU 执行指令的基本时间单位
- 主频：CPU 的时钟频率，时钟周期和主频互为倒数
	- 1 MHz = $10^6$  次/秒
	- 1 GHz = $10^9$ 次/秒
- 指令执行指标：
	- CPI：指令周期，一条指令执行所需要的时钟周期(F → D → E → M → W)
		- 时钟周期 < 机器周期 < 指令周期
		- 机器周期是指完成一个基本操作(如取指令、存储数据)
	- IPC：每周期指令，即每个时钟周期执行的平均指令数
	  $$
		  IPC=\frac{1}{CPI}
	  $$
	- IPS：每秒指令数，即每秒平均能够执行多少条指令
	  $$
		  IPS=\frac{主频}{CPI}
	  $$
	- MIPS：每秒百万指令数，$1\ MIPS=10^6\ IPS$
### 计算机指标
- 字长：指计算机在内部一次操作中能够处理的二进制数字的位数
- 数据通路带宽：是 CPU 和内存之间传输数据的宽度，通常以位为单位表示
- 主存容量：主存储器能够存储信息的最大容量，通常用字节衡量
	- MAR(内存地址寄存器)的位数反应了可寻址范围的最大值，与地址总线的位数一致
- 吞吐量：在单位之间内，系统可以完成的任务数量
# 运算方法和运算器
- 关于浮点数相关的介绍 [[CSAPP#信号的表示和处理]]
- 浮点数精度：2.25 可以很轻松的使用浮点数表示，但是当我们遇到 1.2 这类无法用浮点数精确表示时，我们只能经可能接近这个数，此时就引入了浮点数精度这个概念
- 浮点数加减计算：主要包含**对阶、尾数加减、尾数规格化**等步骤
	- *判断一个数是否规格化的核心原则是：符号位和最高数值位必须不同*
- 数据的十进制数串的表示形式：十进制数的符号位和每个数位都用一个字节表示，如十进制数 98 则可以表示为 00001001 00001000
- BCD 码运算规则：
	- 当前四位结果相加 > 9，必须将该组结果加 6(二进制 0110)进行修正
	- 若 < 9，则无需调整
- 原码、反码、补码、移码
	- 移码的数值部分与补码相同，符号位相反
- 进位、溢出、无符号数、有符号数的具体关系 [[CSAPP#信号的表示和处理]] 
- 求补：从地位到高位，找到第一个 1，保留该 1 和低位的 0，高位的所有位取反
# 存储系统
- 计算机存储系统层次：寄存器、L1 cache、L2 cache、L3 cache、主存、辅助存储，其基本思想主要是上一层存储器是 k下一层存储器的高速缓存，比如当 CPU 要从存储器中存取数据，先访问 Cache，若不在则访问主存，然后从主存送到 Cache，此时就可以用到 [[CSAPP#内存层次结构(Memory Hierarchy)]] 中所说的过程
- Cache-主存：解决 CPU 和主存速度不匹配的问题，主存和 Cache 之间的数据调动是硬件自动完成的，*对所有程序员都是透明的*
- 主存-辅存：解决存储系统的容量问题，之间的数据调动是由硬件和操作系统共同完成的，*对应用程序员是透明的*
> [!note] 透明
> 表示系统在底层自主完成，即程序员不可见
## 内存
- RAM
	- SRAM：主要用于寄存器、Cache
	- DRAM：主要用于主内存、显存

| 特性     | DRAM | SRAM |
| ------ | ---- | ---- |
| 基本存储单元 | 触发器  | 电容   |
| 速度     | 快    | 较慢   |
| 功耗     | 高    | 低    |
| 成本     | 高    | 低    |
| 容量     | 小    | 大    |
| 刷新需求   | 无需刷新 | 定期刷新 |
- Flash 存储：一种非易失性的电子存储设备，利用半导体技术来储存数据，通常用于长期存储，如 USB 闪存、SSD 和移动设备的内部存储，在读取速度上比 RAM 慢，但是优于传统的硬盘驱动器
- ROM：主要用于读取操作，常用于存储固件

| 特征   | RAM     | ROM           |
| ---- | ------- | ------------- |
| 易失性  | 断电即失    | 长期储存          |
| 存储容量 | 大       | 小             |
| 读写能力 | 随机读取和写入 | 通常只读，只读数据不能写入 |
- 片选信号：在计算机主板或者内存条中，通常不会只有一块存储芯片，而是很多芯片连接在一起，为了节省布线空间，这些芯片通常会共享同一组数据线和地址线，片选信号就是来决定那个存储芯片被使用
- 主存扩容：位扩展、字扩展、字位扩展（先进行位扩展，再进行字扩展）
## 外存：
- 机械硬盘：使用磁性存储介质来存取数据的非易失性存储设备
	- 磁头
	- 磁道
	- 柱面
	- 扇区：扇区是磁盘上的最小数据存储单元。磁盘通常被划分为许多扇区，每个扇区可以存储一定数量的数据，**扇区的大小通常是 512 字节或 4 KB**，操作系统和磁盘控制器使用扇区作为数据的最小单元
	- CHS 地址：
	  $$
		位数=[log_2(柱面数量)]+[log_2(磁头号)]+[log_2(扇区号)]
	  $$
	- 平均存取时间：平均存取时间 = 寻道时间 + 旋转延迟时间 + 传输时间
## Cache
- CPU 与 Cache 之间的数据交换以字节为单位，而 Cache 与主存之间的数据交换以 Cache Block 为单位
- Cache 与主存映射方式，常见的有：直接映射、全相联映射、组相连映射，如果和 [[csapp#内存层次结构(Memory Hierarchy)]] 对照来看，直接映射就是 `line` 取 1，全相联就是 `set` 取 1

| 特点           | 直接映射缓存 | 全相联缓存     | 组相连缓存  |
| ------------ | ------ | --------- | ------ |
| 主存块到缓存块的映射关系 | 固定     | 任意        | 组内固定   |
| 硬件复杂度        | 低      | 高         | 介于两者之间 |
| 查找速度         | 快      | 慢         | 介于两者之间 |
| 成本           | 低      | 高         | 介于两者之间 |
| 性能特点         | 简单、低成本 | 无缓存冲突、高性能 | 介于两者之间 |
- Cache 写策略：
	- 命中时：直写法、回写法
	- 未命中时：写分配法、非写分配法
## 虚拟存储器
- 虚拟存储器在物理内存和磁盘存储之间创建了一个抽象的、扩展到内存空间，以提供更大的可用内存容量
- 虚拟内存：进程使用虚拟地址来访问内存中的数据和指令，而不需要了解物理内存的详细情况，进程使用虚拟地址访问虚拟内存，当进程访问虚拟内存时，操作系统会将虚拟地址转化为物理地址，进而根据物理地址去访问物理内存
- 页式虚拟存储器
	- 分页机制：我们通过 MMU 中的硬件寄存器，页表机制寄存器(PTBR)，找到对应进程的页表基地址，然后通过虚拟地址页号找到对应的页表项，然后输出给 MMU，将虚拟地址转化为物理地址，最终根据物理地址到主存中获取数据传送给 CPU
		- 但是页表存放在主存中，就导致了需要**两次访问主存**的问题，本身访问主存对于 CPU 的处理速度来说就很慢，两次显然拖慢了 CPU 的处理速度，因此我们借助局部性原理，引入转换后备缓冲器(TLB)，TLB 位于 CPU 的 MMU 内部，使用的是极快的 SRAM
		- 可以将 TLB 看作是一个容量较小的 cache，只用于缓存经常访问的页表项
	- cache 缺失处理由硬件完成
	- 缺页处理有操作系统通过缺页异常处理程序完成，即由软件完成
	- TLB 缺失处理既可以用硬件，也可以用软件
# 指令系统
- 指令主要包含两个部分：操作码(OP)和地址码(address)
	- 操作码决定指令类型，即作用
	- 地址码指参与指令执行的对象，可以是内存地址、寄存器、立即数
- 指令可以按照操作码、地址个数、指令长度分类
	- 按照指令长度可以分为定长指令集和变长指令集
	- 在定长指令系统中，我们可以采取操作码扩展编码的方式，让操作码本身具有层次结构
	- 二地址指令中，根据操作数的物理位置，分为 SS 型、RS 型、RR 型
- **当我们在计算指令的长度时，如果题目中说明计算机按照字节编址，则说明指令字长应该是字节(8b)的整数倍**
## 寻址方式
- 计算机的寻址方式将决定了操作数的存放位置和访问方式
- 寻址方式是指寻找指令或指令中操作数的有效地址的方式
	- 有效地址可以是主存地址，也可以是虚拟地址
	- 分为指令寻址方式和操作数寻址方式
	- 立即寻址：操作数和指令一起存放在主存里，形式地址 D 就是操作数的值域，比如将一个立即数赋值给寄存器
	- 直接寻址：操作数与指令分开存放在主存里，形式地址 D 储存的是操作数的地址
	- 寄存器寻址：操作数存放在通用寄存器中，指令存放在主存里，形式地址 D 给出的是操作数所在通用地址寄存器的编号
	- 间接寻址：操作数与指令分开存放在主存里，形式地址 D 给出操作数的间接地址，间接地址存储的是操作数的真实地址
	- 寄存器间接寻址：操作数的地址存放在通用寄存器中，操作数和指令分开存放在主存里，形式地址 D 给出的是寄存器的编号
	- 相对寻址：操作数和指令分开存放在主存里，形式地址 D 存储的是相对于 PC 的偏移量的补码表示
	- 变址寻址：操作数和指令分开存放在主存中，寄存器中的内容加上形式地址 D 就是操作数的主存地址，通常用于数组的读取
	- 基址寻址：与变址寻址不同的是，基址寻址控制的是寄存器的内容不变，形式地址 D 值可变
	- 堆栈寻址
# CPU 
- 数据通路指数据在各功能部件（CPU 内的专用/通用寄存器、状态寄存器、ALU、Cache、MMU、浮点运算逻辑、异常与中断处理逻辑、CPU 外的主存等）之间传送到路径
## 控制器
- 控制器主要由指令控制器、时序控制器、控制信号发生器组成
- 控制器分为硬布线控制器和微程序控制器：
	- 硬布线控制器：硬布线控制器组合逻辑单元是控制器的核心，用于产生指令执行所需要的所有控制信号序列
	- 微程序控制器：将 CPU 的每一条机器指令，分解为一些列更小、更基本都为操作，这些微操作的序列，构成了机器指令的微程序
		- 微命令与微操作：控制部件向执行部件发送的**各种控制信号成为微命令**；执行部件收到微命令后**执行的相应操作称为微操作**
		- 微指令和微程序：在一个机器周期内，一组实现某个特定操作功能的相容性微命令构成一条微指令
## 异常与中断
- 异常又称内中断，分为故障、自陷和终止
- 处理过程：发生中断事件 → CPU 收到中断请求 → CPU 进入中断响应周期进行相应处理
	- 对于外部中断，在指令执行结束时，才会进入中断响应周期，不会在收到中断请求后立马进入；但是，如果发生**故障异常**的指令并没有执行完毕，必须立即进入中断响应周期
	- CPU 在中断响应周期主要处理关中断、保存断点、中断识别
		- 关中断：临时禁止中断请求
		- 保存断点：保存中断服务程序结束后应该返回的之前被中断的位置
## 指令流水线
- 在连续向流水线输入指令且执行过程并未发生任何阻塞的情况下，一段 m 段流水线，执行 n 条指令所需要的是中周期数为：m + (n - 1)
	$$
		CPI=\frac{(n+4)}{n}
	$$

# 总线
##  分类
- 按传输方向：单向传输总线、双向传输总线
- 按时序控制方式：同步总线、异步总线
- 按总线功能：控制总线、数据总线(双向)、地址总线(单向)
- 按信号传输模式：并行传输总线、串行传输总线
- 按总线所处位置：片内总线、系统总线、I/O 总线、外部总线
	- 系统总线分为：单总线结构、双总线结构、三总线结构、高性能总线
## 性能指标
- 总线宽度：数据总线所包含的数据线的数量
- 总线时钟频率
- 总线工作频率：一个总线时钟周期内传输数据的次数
- 总线传输周期：完成一次总线操作所耗费的时间，通常包含多个总线时钟周期，包含申请、寻址、传输、结束四个阶段
- 总线带宽：数据总线上的最大数据传输速率，常用单位为 MB/s 和 GB/s（$1MB=10^6B,\ 1GB=10^9B$）
	  $$
	  带宽=\frac{总线宽度}{8} \times 总线工作频率
	  $$
## 总线传输过程
- 总线事务是总线操作的基本单位，包括以下阶段：
	- 申请：传输请求、总线仲裁、获得授权
	- 寻址：启动从设备、从设备相应
	- 传输：写操作则主设备到从设备，读操作则从设备到主设备
	- 结束：撤销请求、控制权交还
- 总线仲裁：
	- 集中式仲裁
		- 链式查询方式：离总线控制器越近的部件，优先级越高
		- 计数器定时查询方式
		- 独立请求方式

|      | 链式查询            | 计数器定时查询        | 独立请求        |
| ---- | --------------- | -------------- | ----------- |
| 控制线数 | 3               | 2 + $[log_2n]$ | 2n + 1      |
| 优点   | 优先级固定；结构简单；扩充容易 | 优先级灵活          | 相应速度快；优先级灵活 |
| 缺点   | 对电路故障敏感；优先级不灵活  | 控制线多；控制复杂      | 控制线多；控制复杂   |
	- 分布式仲裁
## 总线定时
- 同步定时：适用于总线长度较短极总线所接部件的存取时间比较接近的系统
- 异步定时：依靠主从设备的“握手”信号实现定时控制
	- 不互锁：请求和确认信号的**撤销**自动完成，没有依赖关系，一次握手
	- 半互锁：请求信号的撤销依赖确认信号的建立，确认信号自动撤销，二次握手
	- 全互锁：请求信号的撤销依赖确认信号的建立，确认信号的撤销依赖于请求信号的撤销，三次握手
## 输入输出系统
## I/O 接口
- 功能：设备寻址、设备控制、状态监测、数据交互、数据缓冲、格式转换、中断、时序控制、数据检错/纠错
- 结构
	- 内部接口
	- 外部接口
- I/O 端口：是接口中可以被 CPU 直接访问的寄存器，主要有数据端口、状态端口和控制端口
- 编址
	- 统一编址：I/O 设备地址与主存地址统一编址，按不同地址区域来区分
	- 独立编址：I/O 地址空间与主存地址空间相互独立，必须使用专有的 I/O 指令访问
## I/O 控制方式
- 程序查询方式：CPU 通过执行 I/O 程序来实现与 I/O 设备的数据交换
- 程序中断方式：适用于慢速设备
	- 中断响应优先级
		- 不可屏蔽中断 > 内部异常 > 可屏蔽中断
		- 在内部异常中，硬件终止优先级最高，其次是故障和自陷
		- DMA 中断 > I/O 设备传送中断
	- 中断处理优先级：多重中断的实际优先级处理次序
		- 在不使用中断屏蔽
- *程序查询和中断方式都需要 CPU 全程参与 I/O 数据传输，数据必须先从 I/O 设备读取到 CPU 的寄存器中，再从寄存器写入主存，反之亦然*
- DMA 方式：完全由硬件进行成组信息传送到控制方式，核心思想就是绕过 CPU，直接交换数据
	- CPU 参与预处理，CPU 通过初始化程序来设置 DMA 控制器的各参数寄存器的初始值，比如内存首地址，字计数器值等
	- 引入独立的硬件模块，DMA 控制器即 DMAC
		- 组成
			- 地址寄存器：存放要交换数据的主存地址
			- 字计数器：记录传送数据的长度
			- 数据缓冲寄存器：暂存每次传送到数据
			- 命令寄存器：接受 CPU 的控制命令
			- 状态寄存器：向 CPU 反馈 DMAC 的状态
			- DMA 控制逻辑：包括控制电路、时序电路和状态标志，用于修改地址寄存器和字寄存器，指定数据传输方向等
	- DMAC 与 CPU 争用主存问题解决
		- DMA 独占访问：CPU 暂停访问主存
		- 交替访问：将访问周期划分为两个时隙
		- 周期挪用：仅在 DMAC 需要传送数据的具体时刻，借用一个存储周期传送数据

| 对比维度     | 中断驱动方式                                    | DMA 方式                                    |
| -------- | ----------------------------------------- | ----------------------------------------- |
| 请求-应答机制  | 请求的是 CPU 时间<br>响应实际在指令周期结束时刻              | 请求的是总线控制权<br>响应时间是在一个总线事务完成后              |
| 数据传送实现方式 | 通过 CPU 执行程序进行数据传送<br>需要保护和恢复程序执行现场，影响系统性能 | 通过额外的硬件 DMAC 实现数据传送<br>不改变 CPU 现场，不影响系统性能 |
| 主要应用     | 处理各种随机事件                                  | 大量、高速数据传送                                 |
